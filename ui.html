UI Kit — BSI Theme

Витрина существующих повторяющихся элементов темы. Перед вёрсткой нового блока сверяйся со списком слева — если подходящий элемент уже есть, переиспользуй его классы вместо новых. Источники: scss/ui/*.scss, scss/config/vars.scss, template-parts/.

Фон. Фон страниц — серый $bg-page (переводим все шаблоны). Витрина показывает компоненты так, как они лежат на сайте: секции — прямо на сером, карточки — белые сами по себе (padding: 8px, $radius-md, белый фон в базовом правиле). Контролы по умолчанию рассчитаны на белую карточку (серая заливка); если контрол лежит прямо на сером фоне страницы — модификатор --on-gray: .input-item--on-gray, .ui-choice--on-gray, .ui-option--on-gray, .ui-pagination--on-gray, кнопка — .btn-white вместо .btn-gray. Перебивки через body.page-x .card не писать.

Этот файл редактируется вручную. Если добавил новый общий элемент в scss/ui/ — допиши его сюда в соответствующий раздел.

Нумерация текста (как в Word) не используется на проде

.editor-content--numbered не ставит ни один шаблон и нет ни в одном тексте записи на копии прода.

Источник: scss/ui/numbered-content.scss. Класс .editor-content--numbered на контейнере контента из редактора: списки любой вложенности получают сквозные номера 1.1, 1.2.3, 1.2.3.4. Номер раздела берётся из счётчика заголовков <h2>. Если разделов нет — добавить .editor-content--numbered-flat, счёт пойдёт с первого уровня. Списки в редакторе остаются обычными <ul>/<ol>, номера рисует CSS. На экранах ≤768px с третьего уровня отступ не растёт — вложенность видно по номеру.

Страховой случай

  • Страховщик обеспечивает защиту по договору от следующих рисков:
    • «Медицинская помощь» — непредвиденные расходы при обращении в медицинское учреждение.
    • «Депортация» — расходы, связанные с депортацией застрахованного.

Подтверждение брони и спецпредложения (.hp-badge)

Хаб отдаёт по каждой ночи confirmation: instant — оператор подтверждает сразу, request — сначала спрашивает отель. Отмечаем только первое: под запрос продаётся большинство ночей, и метка на каждом втором номере ничего не различает. Плашки рисуются у названия номера, в шапке отеля и в списке спецпредложений; заливки нет — карточка номера не должна рябить. Метки «Мало мест» нет намеренно: оператор сообщает наличие буквами, без количества, и подтвердить такую надпись нечем.
