UI Kit — BSI Theme

Витрина существующих повторяющихся элементов темы. Перед вёрсткой нового блока сверяйся со списком слева — если подходящий элемент уже есть, переиспользуй его классы вместо новых. Источники: scss/ui/*.scss, scss/config/vars.scss, template-parts/.

Этот файл редактируется вручную. Если добавил новый общий элемент в scss/ui/ — допиши его сюда в соответствующий раздел.

Пагинация

Источник: scss/ui/pagination.scss, разметку печатает bsi_pagination() (inc/helpers/pagination.php). Одна пагинация на весь сайт: обёртка .ui-pagination, ссылки .page-numbers от paginate_links(). Текущая страница — .current (красная, hover отключён), многоточие — .dots, наведение на остальные — чёрный фон с белым текстом. «Назад»/«Вперёд» — шеврон Lucide .ui-pagination__icon плюс подпись .ui-pagination__label. Каталоги, которые рисуют пагинацию на клиенте, берут те же стрелки из js/modules/services/pagination-arrows.js.

Назад 1 2 3 … 12 Вперёд 
<?php
bsi_pagination([
  'total'   => (int) $query->max_num_pages,
  'current' => $paged,
], ['class' => 'country-sights-pagination']);

// AJAX-каталог: контейнер нужен всегда, даже на одной странице
bsi_pagination($args, [
  'class'  => 'js-news-pagination',
  'attrs'  => ['data-tours-pagination' => ''],
  'always' => true,
]);

// Ответ AJAX — только ссылки, обёртка уже на странице
echo bsi_pagination_links(['total' => $max_pages, 'current' => $paged]);
?>

Нумерация текста (как в Word)

Источник: scss/ui/numbered-content.scss. Класс .editor-content--numbered на контейнере контента из редактора: списки любой вложенности получают сквозные номера 1.1, 1.2.3, 1.2.3.4. Номер раздела берётся из счётчика заголовков <h2>. Если разделов нет — добавить .editor-content--numbered-flat, счёт пойдёт с первого уровня. Списки в редакторе остаются обычными <ul>/<ol>, номера рисует CSS. На экранах ≤768px с третьего уровня отступ не растёт — вложенность видно по номеру.

Красная строка

Источник: scss/components/editor-styles.scss + inc/admin/paragraph-indent.php. В классическом редакторе — кнопка-иконка в панели (после выравниваний), хоткей Alt+Shift+Z: ставит на абзац класс .is-style-indent. Выключку по ширине даёт родная кнопка «По ширине». В Gutenberg (если Classic Editor отключат) — стили блоков «Красная строка» / «Красная строка + по ширине» у «Абзаца» и «Группы»; у группы отступ получают все абзацы внутри.

.is-style-indent-justify

Страховщик осуществляет оценку страхового риска, получает страховые премии (страховые взносы), определяет размер убытков (ущерба, вреда), производит страховые выплаты, осуществляет иные действия, связанные с исполнением обязательств по договору страхования.

Сайт Компании — официальный сайт страховой компании в информационно-телекоммуникационной сети «Интернет».
